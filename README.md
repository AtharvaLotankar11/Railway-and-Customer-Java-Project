## 🚀 Installation

### Prerequisites

Before you begin, ensure you have:

- ☕ **Java 8** or higher installed
- 💻 Any Java IDE (IntelliJ IDEA, Eclipse, or NetBeans)

### Quick Start

```bash
# 1️⃣ Clone the repository
git clone https://github.com/AtharvaLotankar11/Railway-and-Customer-Java-Project.git

# 2️⃣ Navigate to project directory
cd Railway-and-Customer-Java-Project

# 3️⃣ Compile the application
javac src/RailwayManagementApp.java

# 4️⃣ Run the application
java -cp src RailwayManagementApp
```

> **💡 Pro Tip:** You can also run directly from your IDE by executing the `main` method in `RailwayManagementApp.java`

## 📖 Usage

### 👥 Managing Customers

<details>
<summary><b>Click to expand Customer Management Guide</b></summary>

1. **Navigate** to the "👥 Customer Management" tab
2. **Fill in** customer details in the form fields
3. **Click** "Add Customer" to create new records
4. **Select** a row in the table to edit existing customers
5. **Update** customer information and click "Update Customer"
6. **Delete** customers using "Delete Customer" (confirmation required)
7. **Clear** all fields with the "Clear Form" button

</details>

### 🚂 Managing Railways

<details>
<summary><b>Click to expand Railway Management Guide</b></summary>

1. **Switch** to the "🚂 Railway Management" tab
2. **Enter** train details (name, route, timings)
3. **Select** source and destination from 35+ stations
4. **Use** time format HHMM (e.g., `1430` for 2:30 PM)
5. **Perform** CRUD operations similar to customer management
6. **View** all trains in the interactive table

</details>
